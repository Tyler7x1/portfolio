# Jayprakash Malik · Portfolio

My personal portfolio: independent research, projects and an interactive demo, built while preparing to apply for a Master's degree in Business Informatics.

**Live site:** https://jaypfolio.vercel.app

## What's on the site

- **Home:** introduction, cv download and featured work
- **About:** education and skills
- **Projects:** independent research, a team capstone project and a Python analytics project
- **Demos:** an interactive sales dashboard built on synthetic data
- **Blog:** written articles

### Featured work

- **Behind the Storefront:** an independent exploratory study of clothing retail operations, based on one semi-structured interview with a Store Manager. It is not an official company report, and the retailer is not named. What the manager said is labelled separately from my own interpretation, and uncertain details are flagged.
- **Python for Business Analytics:** learning notes on which Python fundamentals matter for business analytics, with an interactive demo.
- **Sales dashboard:** filters, switchable charts and drill-down on dummy data for a fictional electronics retailer. All figures are synthetic.

## Tech stack

- [Next.js](https://nextjs.org) (App Router) with React and TypeScript
- [Tailwind CSS](https://tailwindcss.com) v4 with the typography plugin
- MDX for articles (`@next/mdx`, `remark-gfm`)
- `next-themes` for the light and dark toggle
- `react-icons` for skill logos
- Charts are drawn by hand in SVG, with no charting library
- Deployed on [Vercel](https://vercel.com)

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

Other scripts: `npm run build`, `npm run start` and `npm run lint`.

## Project structure

```
app/            Pages: home, about, projects, demos, blog, plus SEO files
components/     Navbar, footer, theme toggle, dashboard, article components
content/        Articles written in MDX
lib/            Article helpers, dashboard data generator, site settings
public/         CV, project GIF and static files
```

## Adding content

**A new article:** create `content/my-article.mdx`. The blog list and the article page are generated from the file.

```mdx
export const metadata = {
  title: "Article title",
  subtitle: "Optional subtitle",
  description: "One sentence shown on the blog list.",
  date: "2026-01-01",
  category: "Optional label",
};

## First section

Text goes here.
```

Components available inside articles:

- `<Callout type="manager | interpretation | uncertain">` for labelled notes
- `<Flow title="..." steps={[...]} note="..." />` for process diagrams
- `<StockCoverage />` for the interactive stock coverage demo

**A new project:** add an entry to the `projects` list in `app/projects/page.tsx`.

## About the data

- The *Behind the Storefront* study rests on one interview with one manager at one store, and the retailer is not named.
- The sales dashboard uses synthetic data generated by a seeded script. It does not describe any real company.

## Deployment

The site deploys on Vercel. Every push to `main` triggers a new production build.
